# Blogz - A Minimalist Blog Website

Blogz is a lightweight, minimalist blog website designed for fast loading times and a soothing reading experience.

## Features

- Clean, minimalist design with a warm color palette
- Responsive layout that works on desktop and mobile devices
- Lightning-fast performance with minimal JavaScript
- Easy-to-read typography optimized for long-form content
- Contact form for reader engagement

## Technology Stack

Built with simple, vanilla web technologies:

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

## Getting Started

To run this website locally:

1. Clone this repository
2. Open `index.html` in your browser

No build process or dependencies required!

## Adding New Blog Posts

To add a new blog post:

1. Create a new HTML file in the `posts/` directory
2. Copy the structure from an existing post
3. Update the content, title, and metadata
4. Add a link to your new post on the homepage

## Performance Considerations

This blog was built with performance in mind:

- Minimal external dependencies
- Optimized images (when added)
- Efficient CSS with minimal redundancy
- JavaScript used only where necessary
